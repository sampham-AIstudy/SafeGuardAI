NHIỆM VỤ: PHASE 2E — đánh giá module URL cho báo cáo đồ án: cập nhật eval/url_eval.py + tạo eval/ablation.py + cập nhật eval/RESULTS.md. Đã commit đến 6b0ab3b; module url_analysis đã tích hợp (golden v1 85%, v2 73.6%, FPR v2 9.1%). Đọc eval/url_eval.py hiện có (đo baseline cũ A-Baseline bằng ExplainableAgent đời đầu: identity recall 22.1%, aug recall 26.9%, benign FPR 7.4%, AUROC 0.579) và eval/RESULTS.md. File được phép sửa/tạo: eval/url_eval.py, eval/ablation.py (mới), eval/RESULTS.md, tests/test_eval_scripts.py (mới, test nhanh). KHÔNG sửa codebase/.
E1 url_eval.py: thêm tham số --predictor {baseline,url_module} (mặc định url_module) và --out. Predictor url_module: dùng get_shared_url_analyzer()/UrlAnalyzer với blacklist dựng CHỈ từ split train+val của PhishVN ver2 (PhishBlacklist.from_dataset(..., exclude_splits=['test']) hoặc API tương đương - đọc blacklist.py/dataset_loader.py để dùng đúng; tuyệt đối KHÔNG để test URL nằm trong blacklist), dự đoán phishing nếu url_risk_score >= 40 (và ghi thêm điểm liên tục url_risk_score để tính AUROC). Giữ seed 42, mẫu phishing 1000/5125 (tham số --sample-phish) và toàn bộ benign test. Các phép biến đổi augmentation đã có (identity, defang, percent-host, zero-width, fullwidth, userinfo-decoy, open-redirect, base64-param, shortener, domain trần, dấu câu cuối...) giữ nguyên; thêm các phép: homoglyph_cyrillic (thay a/e/o/p/c/x/i trong nhãn đầu bằng ký tự Cyrillic tương ứng, tạo bằng chr/escape), punycode_idn (encode IDNA), ip_decimal (nếu host trong tập là IP), backslash_confusion (https://evil-host\@brand.com.vn/), nested_redirect (google.com/url?q=<url đã percent-encode>), double_encoding, hex_param. Báo recall theo TỪNG phép, benign FPR cho các phép bảo toàn nghĩa (identity, domain trần, dấu câu cuối, chữ hoa, defang), AUROC (thuần Python, xử lý hòa), tỉ lệ phát hiện kỹ thuật che giấu đúng mã (ví dụ homoglyph => có HOMOGLYPH_BRAND hoặc MIXED_SCRIPT/PUNYCODE_HOST). Chú ý artifact userinfo_decoy/base64_param: báo thêm trung bình đã loại hai phép này. Ghi JSON kết quả vào --out (mặc định eval/results/url_eval_<predictor>_<ts>.json).
E2 ablation.py: chạy tuần tự (mỗi cấu hình trong một subprocess riêng, đặt biến môi trường SAFEGUARD_OFFLINE=1 và các biến cần thiết, blank mọi API key, để tránh cache settings/dữ liệu) các cấu hình: (B) SAFEGUARD_URL_MODULE=off — hành vi Phase 1 + T1.6; (C) module bật (mặc định). Với mỗi cấu hình chạy eval/run_eval.py trên golden v1, v2 (toàn bộ, dev, test) với --out ra thư mục tạm và đọc JSON metrics (macro_f1, accuracy_exact, binary_high_plus.recall, fpr_benign, critical_recall_strict, latency.p95_ms), và chạy url_eval.py (--predictor baseline cho A, --predictor url_module cho C; B dùng baseline vì URL module tắt) với --sample-phish 300 khi chạy nhanh (--quick) hoặc 1000 khi đầy đủ. Ghi một bảng markdown (bảng ablation) vào stdout và, với --write-results, cập nhật có kiểm soát khối giữa hai marker `<!-- ABLATION:START -->` và `<!-- ABLATION:END -->` trong eval/RESULTS.md (tạo marker nếu chưa có). Hàng A (code gốc Phase 0) có số liệu đo tay đã biết: golden v1 exact 65.0% (13/20), v2 exact 40.3%, FPR v2 18.2%, critical recall chặt v2 40% — ghi là 'đo ở Phase 0 (commit 250d938), không chạy lại' kèm cột nguồn. Các cột: macro-F1, accuracy exact, recall HIGH+, FPR>=MEDIUM, recall CRITICAL chặt, p95 ms, URL identity recall, URL aug recall (trung bình và loại artifact), URL benign FPR, AUROC.
E3 Tests nhanh tests/test_eval_scripts.py (không chạy đầy đủ dataset; dùng 20 URL giả hoặc fixture nhỏ): predictor url_module trên 12 URL che giấu mẫu (tên miền giả) có recall >= 10/12; 12 URL lành tính không bị báo; các phép augmentation sinh chuỗi đúng định dạng (ví dụ homoglyph chứa ký tự non-ASCII, punycode bắt đầu 'xn--', backslash chứa '\\@'); compute_auroc đúng trên ví dụ tay (tính tay 2 ví dụ, gồm hòa); ablation.py parse được kết quả giả (hàm định dạng bảng) và cập nhật khối marker không phá phần còn lại của RESULTS.md (dùng file tạm).
Chạy CHỈ: `.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider tests/test_eval_scripts.py` (foreground timeout 120) và chạy thử nhanh `.venv\Scripts\python.exe eval\url_eval.py --predictor url_module --sample-phish 100 --out %TEMP%\u.json` (timeout 120; nếu quá lâu thì hủy và giảm mẫu).
