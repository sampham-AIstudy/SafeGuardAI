Proposed SafeGuard Detection architecture

Research design. The Agent Controller chooses the next check. The Execution Host controls which data, tools, and models the controller can use.

Data flow

  1. The Host binds the observed boundary and reads the applicable version of conversation state from Memory.
  2. The controller proposes the next check. The Host validates it and brokers the model or tool call. The controller receives the result and can choose another check within the same boundary.
  3. The Host validates the final assessment and commits the applicable state. A material gap can produce an insufficient-evidence result. Execution failures retain their separate outcome.
  4. Warning Policy acts on the Detection result. A later message establishes a new boundary for the next assessment.
